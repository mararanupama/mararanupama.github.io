# Anupama Venugopalan Portfolio

Static portfolio site for GitHub Pages with a custom domain of `anupamav.com`.

## Preview locally

Open `index.html` in a browser, or serve the folder locally with any simple static server.

## Publish after approval

1. Create a public GitHub repository.
2. Push these files to the repository's default branch.
3. In GitHub, open Settings > Pages and publish from the default branch root.
4. Keep the `CNAME` file in the repository root with `anupamav.com`.
5. In GoDaddy DNS, point the apex domain to GitHub Pages using A records and add a CNAME for `www`.

GitHub Pages DNS values should be checked against GitHub's current documentation before making DNS changes.
